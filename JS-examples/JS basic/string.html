        Завдання: У тебе є слово "JavaScript". За допомогою методу charAt() знайди і виведи перший і останній символ цього слова.

        Розв'язок:

        let word = "JavaScript";
        let firstChar = word.charAt(0);
        let lastChar = word.charAt(word.length - 1);
        console.log("Перший символ:", firstChar);  // "J"
        console.log("Останній символ:", lastChar);  // "t"
