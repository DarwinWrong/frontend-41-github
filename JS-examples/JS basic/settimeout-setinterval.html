setTimeout() використовується для запуску функції через певний час (в мілісекундах).
    setTimeout(function, delay, ...args);

    Де краще використовувати?
    Для відкладених операцій (наприклад, показ повідомлення через певний час).
    Для симуляції асинхронних запитів.
Створи кнопку, при натисканні на яку через 2 секунди виводиться привітання "Привіт, як справи?". Використовуємо setTimeout() для затримки. 

    setInterval() виконує функцію з певним інтервалом часу.
    setInterval(function, delay, ...args);

    Де краще використовувати?
    Для постійних оновлень (наприклад, таймер або анімації).
    Для періодичних запитів на сервер.
Створи лічильник, який збільшується на 1 кожну секунду, і показує поточне значення на сторінці. Для цього використовуй setInterval().
