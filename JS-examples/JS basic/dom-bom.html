Таблиця з основними властивостями об'єкта window

Властивість Опис
window.document Посилання на об'єкт document, який представляє HTML-сторінку.
window.location Об'єкт, що містить URL поточної сторінки і методи для його зміни.
window.history Об'єкт для роботи з історією перегляду браузера.
window.navigator Інформація про браузер і пристрій користувача.
window.screen Інформація про екран користувача (ширина, висота тощо).
window.innerWidth Внутрішня ширина вікна браузера (без рамок).
window.innerHeight Внутрішня висота вікна браузера (без рамок).
window.outerWidth Повна ширина вікна браузера (включаючи рамки).
window.outerHeight Повна висота вікна браузера (включаючи рамки).
window.scrollX Поточне горизонтальне прокручування сторінки.
window.scrollY Поточне вертикальне прокручування сторінки.
window.localStorage Локальне сховище для збереження даних між сеансами.
window.sessionStorage Сховище для збереження даних протягом сесії.
window.alert() Відображає модальне діалогове вікно з повідомленням.
window.confirm() Відображає модальне вікно з питанням (OK/Cancel).
window.prompt() Відображає діалогове вікно для введення тексту.
window.setTimeout() Виконує функцію через певний час.
window.setInterval() Виконує функцію періодично через певний інтервал.
window.clearTimeout() Зупиняє виконання setTimeout().
window.clearInterval() Зупиняє виконання setInterval().
window.open() Відкриває нове вікно або вкладку.
window.close() Закриває поточне вікно (якщо дозволено).
window.focus() Фокусується на поточному вікні.
window.blur() Знімає фокус з поточного вікна.
window.matchMedia() Перевіряє відповідність медіа-запиту (наприклад, розмір екрану).
window.getComputedStyle() Отримує стилі елемента.
window.requestAnimationFrame() Запускає анімацію в наступному кадрі оновлення екрану.
window.cancelAnimationFrame() Скасовує запит requestAnimationFrame().
window.addEventListener() Додає обробник подій.
window.removeEventListener() Видаляє обробник подій.

Ось таблиця, яка показує, які методи повертають масивоподібну структуру (HTMLCollection або NodeList), а які повертають окремий елемент:

Метод Що повертає Тип поверненого значення Динамічне оновлення Доступ через [0]
document.getElementById("id") ❌ Один елемент або null Element ❌ Ні ❌ Нема сенсу
document.getElementsByClassName("class") ✅ Колекція (навіть якщо 1) HTMLCollection ✅ Так ✅ Так
document.getElementsByTagName("tag") ✅ Колекція (навіть якщо 1) HTMLCollection ✅ Так ✅ Так
document.querySelector("selector") ❌ Один елемент або null Element ❌ Ні ❌ Нема сенсу
document.querySelectorAll("selector") ✅ Колекція (NodeList) NodeList ❌ Ні ✅ Так
document.forms ✅ Колекція форм (<form>) HTMLCollection ✅ Так ✅ Так
document.images ✅ Колекція картинок (<img>) HTMLCollection ✅ Так ✅ Так
document.links ✅ Колекція посилань (<a href>) HTMLCollection ✅ Так ✅ Так
document.childNodes ✅ Колекція дочірніх вузлів NodeList ❌ Ні ✅ Так

🔥 Ключові висновки:

  1. Повертають ОКРЕМИЙ елемент (Element):

    • getElementById("id")
    • querySelector("selector")
    • ❌ Не потребують [0], бо повертають конкретний елемент.

  2. Повертають МАСИВОПОДІБНУ КОЛЕКЦІЮ (HTMLCollection):

    • getElementsByClassName("class")
    • getElementsByTagName("tag")
    • document.forms, document.images, document.links
    • ✅ Потребують [0], [1] або for.

  3. Повертають МАСИВОПОДІБНУ КОЛЕКЦІЮ (NodeList):

    • querySelectorAll("selector")
    • document.childNodes
    • ✅ Потребують [0], [1] або forEach().

  4. Динамічне оновлення:

    • HTMLCollection оновлюється автоматично при зміні DOM.
    • NodeList не оновлюється (виняток — childNodes, який є "живим").
