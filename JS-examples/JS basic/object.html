Умова: У вас є об'єкт, що описує улюблений фільм. 
      За допомогою методу Object.keys() вам потрібно вивести всі ключі цього об'єкта.


      const favoriteMovie = {
        title: "Inception",
        director: "Christopher Nolan",
        year: 2010,
        genre: "Sci-Fi"
      };

      const keys = Object.keys(favoriteMovie);
      console.log(keys); // Очікуємо: ["title", "director", "year", "genre"]
    
      Умова: Використовуйте Object.values(), щоб отримати всі значення з об'єкта про ваш улюблений фільм.


      const favoriteMovie = {
        title: "Inception",
        director: "Christopher Nolan",
        year: 2010,
        genre: "Sci-Fi"
      };

      const values = Object.values(favoriteMovie);
      console.log(values); // Очікуємо: ["Inception", "Christopher Nolan", 2010, "Sci-Fi"
    
      Умова: Використовуйте Object.entries(), щоб отримати всі пари [ключ, значення] 
      і підрахувати кількість властивостей об'єкта.

      const favoriteMovie = {
        title: "Inception",
        director: "Christopher Nolan",
        year: 2010,
        genre: "Sci-Fi"
      };

      const entries = Object.entries(favoriteMovie);
      console.log(entries.length); // Очікуємо: 4
    
      Умова: Ми маємо масив пар [ключ, значення], використовуючи Object.fromEntries(), створіть об'єкт.

      const movieArray = [
        ["title", "Inception"],
        ["director", "Christopher Nolan"],
        ["year", 2010],
        ["genre", "Sci-Fi"]
      ];

      const movieObject = Object.fromEntries(movieArray);
      console.log(movieObject);
      // Очікуємо:
      // {
      //   title: "Inception",
      //   director: "Christopher Nolan",
      //   year: 2010,
      //   genre: "Sci-Fi"
      // }
    
      Умова: У вас є два об'єкти. Використовуйте Object.assign(), щоб з'єднати їх в один об'єкт.

      const movieDetails = {
        title: "Inception",
        director: "Christopher Nolan"
      };

      const movieYear = {
        year: 2010,
        genre: "Sci-Fi"
      };

      const fullMovie = Object.assign({}, movieDetails, movieYear);
      console.log(fullMovie);
      // Очікуємо:
      // {
      //   title: "Inception",
      //   director: "Christopher Nolan",
      //   year: 2010,
      //   genre: "Sci-Fi"
      // }
    
      Використайте метод Object.hasOwn(), щоб перевірити, чи є у вашому об'єкті властивість year.


      const favoriteMovie = {
        title: "Inception",
        director: "Christopher Nolan",
        year: 2010,
        genre: "Sci-Fi"
      };

      const hasYear = Object.hasOwn(favoriteMovie, "year");
      console.log(hasYear); // Очікуємо: true
