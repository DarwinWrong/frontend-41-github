Властивість Параметри Опис параметрів
display flex, inline-flex - flex: створює блоковий flex-контейнер.
- inline-flex: створює стрічковий (inline) flex-контейнер.
flex-direction row, row-reverse, column, column-reverse - row: розміщує елементи зліва направо.
- row-reverse: справа наліво.
- column: зверху вниз.
- column-reverse: знизу вгору.
flex-wrap nowrap, wrap, wrap-reverse - nowrap: елементи розміщуються в один рядок без перенесення.
- wrap: дозволяє переносити елементи на новий рядок.
- wrap-reverse: перенос в зворотному напрямку.
flex-flow <flex-direction> <flex-wrap> Поєднує flex-direction і flex-wrap для одночасного налаштування напрямку та перенесення flex-контейнера.
justify-content flex-start, flex-end, center, space-between, space-around, space-evenly - flex-start: вирівнює елементи на початку контейнера.
- flex-end: на кінці.
- center: вирівнює по центру.
- space-between: рівний простір між елементами.
- space-around: рівний простір навколо кожного елемента.
- space-evenly: рівний простір між елементами та краями контейнера.
align-items flex-start, flex-end, center, baseline, stretch - flex-start: вирівнює елементи на початку поперечної осі.
- flex-end: на кінці.
- center: по центру.
- baseline: вирівнює за базовою лінією тексту.
- stretch: розтягує елементи на всю висоту контейнера.
align-content flex-start, flex-end, center, space-between, space-around, stretch - flex-start: вирівнює всі рядки на початку контейнера.
- flex-end: на кінці.
- center: по центру.
- space-between: рівний простір між рядками.
- space-around: рівний простір навколо кожного рядка.
- stretch: розтягує рядки на всю висоту контейнера.
order Числове значення Встановлює порядок відображення елементів; менше значення відображається раніше, більше — пізніше.
flex-grow Числове значення (0 або більше) Вказує, наскільки елемент може збільшуватися відносно інших елементів для заповнення доступного простору. Значення 0 означає, що елемент не буде збільшуватися.
flex-shrink Числове значення (0 або більше) Вказує, наскільки елемент може зменшуватися, якщо простору недостатньо. Значення 0 означає, що елемент не буде зменшуватися.
flex-basis auto, content, <розмір> Визначає базовий розмір елемента до застосування властивостей flex-grow і flex-shrink.
- auto: розмір визначається вмістом.
- content: розмір відповідає розміру вмісту.
- <розмір>: вказується конкретний розмір (наприклад, 100px, 50%).
flex <flex-grow> <flex-shrink> <flex-basis> Коротка форма для задання flex-grow, flex-shrink, і flex-basis одночасно. Наприклад, flex: 1 1 0 означає, що елемент може як збільшуватися, так і зменшуватися з початковим розміром 0.
align-self auto, flex-start, flex-end, center, baseline, stretch Задає вирівнювання окремого елемента вздовж поперечної осі, перевизначаючи значення align-items для цього елемента.
- auto: бере значення align-items контейнера.
- Інші значення аналогічні align-items.
