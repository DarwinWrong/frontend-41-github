Назва поля HTML-форм Атрибути Властивості атрибутів Короткий опис
<input> type text, password, email, number, checkbox, radio, submit, reset, button, hidden, file, тощо Поле для вводу даних різного типу.
name Текстове значення Унікальний ідентифікатор даних у формі.
value Будь-яке текстове значення Значення за замовчуванням або передане значення поля.
placeholder Текстове значення Підказка для користувача всередині поля.
required true, false Робить поле обов’язковим для заповнення.
readonly true, false Поле доступне лише для читання.
disabled true, false Поле недоступне для взаємодії.
maxlength Цифрове значення Максимальна кількість символів для вводу.
min, max Числове або датове значення Мінімальне та максимальне значення для чисел або дат.
pattern Регулярний вираз Шаблон, за яким повинні відповідати введені дані.
<textarea> name Текстове значення Ідентифікатор поля вводу багаторядкового тексту.
rows, cols Числові значення Кількість рядків та стовпців текстового поля.
placeholder Текстове значення Підказка для користувача.
maxlength Цифрове значення Максимальна кількість символів.
required, readonly, disabled true, false Обов’язковість, доступність для редагування або взаємодії.
<select> name Текстове значення Ідентифікатор поля вибору.
required true, false Поле обов’язкове для вибору.
disabled true, false Заборона взаємодії з полем.
multiple true, false Дозволяє вибір кількох значень.
<option> value Текстове значення Значення, яке передається при виборі опції.
selected true, false Вказує, чи вибраний цей пункт за замовчуванням.
disabled true, false Забороняє вибір пункту.
<button> type submit, reset, button Визначає тип кнопки: надсилання, скидання або звичайна кнопка.
name Текстове значення Ідентифікатор кнопки.
value Будь-яке текстове значення Значення, яке передається при взаємодії з кнопкою.
disabled true, false Забороняє взаємодію з кнопкою.
<label> for ID іншого елемента Прив’язка до елемента форми, якого стосується мітка.
<fieldset> disabled true, false Заборона редагування всіх полів у групі.
name Текстове значення Ідентифікатор групи.
<form> action URL-адреса Місце надсилання даних форми.
method GET, POST Метод надсилання даних.
enctype application/x-www-form-urlencoded, multipart/form-data, text/plain Кодування даних при відправленні.
target _self, _blank, _parent, _top Вказує, де відкрити результат (у поточному чи новому вікні).
novalidate true, false Заборона автоматичної валідації форми.
autocomplete on, off Вказує, чи дозволено автозаповнення полів форми.
<datalist> id Текстове значення Унікальний ідентифікатор для прив'язки до <input>.
<output> name Текстове значення Ідентифікатор поля виводу даних.
for ID елементів Вказує залежність виведеного результату.
<progress> value Числове значення Поточний прогрес.
max Числове значення Максимальне значення прогресу.
<meter> value Числове значення Поточне значення.
min, max Числові значення Мінімальне та максимальне значення.
low, high, optimum Числові значення Межі низького, високого та оптимального значення.
<legend> Немає специфічних атрибутів - Використовується для надання заголовка групи елементів форми, визначеної через <fieldset>.
