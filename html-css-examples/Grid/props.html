Таблиця з усіма властивостями CSS Grid

Властивість Опис Параметри Додатковий опис
display Задає елемент як Grid-контейнер. grid, inline-grid grid створює блоковий контейнер, inline-grid — інлайновий контейнер.
grid-template-columns Визначає кількість та розміри стовпців у сітці. px, %, fr, auto, repeat(), minmax() Можна використовувати повторення з repeat() або мінімальні/максимальні значення.
grid-template-rows Визначає кількість та розміри рядків у сітці. px, %, fr, auto, repeat(), minmax() Аналогічно до grid-template-columns, але для рядків.
grid-template-areas Створює шаблон іменованих областей для сітки. Імена областей (рядки через лапки) Використовується для позиціонування елементів за іменами областей.
grid-template Скорочена властивість для grid-template-rows, columns, areas. Комбінований запис Дозволяє одночасно задати розміри та шаблон областей.
grid-column-gap (застаріла) Відстань між стовпцями сітки. Розмір (наприклад, 10px) Використовуйте column-gap у нових версіях CSS.
grid-row-gap (застаріла) Відстань між рядками сітки. Розмір (наприклад, 10px) Використовуйте row-gap у нових версіях CSS.
gap Відстань між рядками та стовпцями одночасно. Один або два значення gap: 10px — однакові відстані; gap: 10px 20px — різні для рядків і стовпців.
grid-auto-flow Визначає порядок розташування елементів у сітці. row, column, dense dense заповнює пусті місця найменшими елементами.
grid-auto-columns Задає розмір автоматично створених стовпців. Розмір: auto, px, fr, minmax() Використовується, коли елементи виходять за межі визначених стовпців.
grid-auto-rows Задає розмір автоматично створених рядків. Розмір: auto, px, fr, minmax() Аналогічно до grid-auto-columns, але для рядків.
grid-column Визначає, які стовпці повинен займати елемент. start / end (наприклад, 1 / 3) Задає початкову та кінцеву лінію для стовпців.
grid-row Визначає, які рядки повинен займати елемент. start / end (наприклад, 1 / 2) Аналогічно до grid-column, але для рядків.
grid-column-start Задає початкову лінію стовпця для елемента. Номер лінії або ім'я Використовується для точного позиціонування елементів.
grid-column-end Задає кінцеву лінію стовпця для елемента. Номер лінії або ім'я Можна комбінувати з span для охоплення кількох ліній (span 2).
grid-row-start Задає початкову лінію рядка для елемента. Номер лінії або ім'я Використовується для позиціонування по рядках.
grid-row-end Задає кінцеву лінію рядка для елемента. Номер лінії або ім'я Аналогічно до grid-column-end.
grid-area Скорочена властивість для grid-row-start, grid-column-start тощо. row-start / column-start / row-end / column-end Дозволяє одночасно задати всі позиції для елемента.
justify-items Вирівнює всі елементи у сітці по горизонталі всередині осередків. start, end, center, stretch Застосовується до всього контейнера.
align-items Вирівнює всі елементи у сітці по вертикалі всередині осередків. start, end, center, stretch Аналогічно до justify-items.
justify-self Вирівнює один елемент по горизонталі у сітці. start, end, center, stretch Застосовується індивідуально до елемента.
align-self Вирівнює один елемент по вертикалі у сітці. start, end, center, stretch Використовується для індивідуального позиціонування елемента.
justify-content Вирівнює всю сітку по горизонталі всередині контейнера. start, end, center, space-between, space-around, space-evenly Розподіляє вільний простір горизонтально між сіткою та контейнером.
align-content Вирівнює всю сітку по вертикалі всередині контейнера. start, end, center, space-between, space-around, space-evenly Використовується, коли сітка менша за контейнер.
grid-row-start: 2; grid-row-end: span 2; grid-row: 2 / span 2;
grid-column-start: 2; grid-column-end: span 2; grid-column: 2 / span 2; grid-row-start/grid-column-start/grid-row-end/grid-column-end => grid-area: 2 / 1 / 4 / 3;
row-gap: 10px; column-gap: 15px; gap: 10px 15px;
align-items: center; justify-items: start; place-items: center start;
align-content justify-content place-content: space-between center;
