Основні атрибути:

  1. src: URL сторінки, яку потрібно вбудувати.
  2. width та height: Розміри фрейму.
  3. title: Опис контенту для доступності.
  4. sandbox: Обмежує можливості вбудованого контенту для підвищення безпеки.
  5. allow: Дозволяє специфічні API чи функціональність (наприклад, геолокація, камера).
  6. loading: Оптимізація завантаження:
    • lazy: Завантаження відкладено до моменту, коли iframe з’явиться в полі зору.
    • eager: Завантаження виконується одразу.

Доступні значення sandbox:

  • allow-same-origin: Дозволяє iframe працювати в контексті того ж джерела (необхідно для JavaScript, але знижує безпеку).
  • allow-scripts: Дозволяє виконання JavaScript, але без створення нових спливаючих вікон чи форм.
  • allow-popups: Дозволяє відкриття нових вікон.
  • allow-forms: Дозволяє надсилання форм.
  • allow-downloads: Дозволяє завантаження файлів. 
        
          iframe
          src="https://example.com"
          sandbox="allow-scripts allow-same-origin">
          /iframe>

Відео з YouTube:


      iframe
      src="https://www.youtube.com/embed/dQw4w9WgXcQ"
      width="560"
      height="315"
      frameborder="0"
      allowfullscreen
      >
      /iframe>

        iframe
        src="https://www.google.com/maps/embed?pb=!1m18"
        width="600"
        height="450"
        style="border: 0"
        allowfullscreen
        >
        /iframe>
