Як це працює: Якщо ви задаєте ширину, браузер автоматично розраховує висоту на основі заданого співвідношення сторін. Якщо задаєте висоту, браузер розраховує ширину. У вашому випадку, висота задана через height: 20%, тому ширина автоматично буде рівною цій висоті, забезпечуючи квадратну форму. Типові приклади використання: Для підтримки співвідношення сторін у зображеннях чи відео (наприклад, 16:9 для відео або 1:1 для аватарок). Для створення адаптивних блоків з фіксованими пропорціями.
